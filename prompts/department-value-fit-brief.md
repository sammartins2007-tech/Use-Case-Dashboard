(2) the priorities file given in your task (per customer: headline and P1..P6 from the Customers-704f56 Priorities column): per customer, the leadership headline and priorities P1..P6 taken from the customer's latest annual report. - "PriorityWhy": "" if no fit; otherwise one sentence naming the priority title and how this use case advances it.

OUTPUT: JSON {"<id>": {"Department": "...", "ValueLevel": "...", "ValueBasis": "...", "PriorityFit": "...", "PriorityWhy": "..."}, ...} to the output path in your task, covering EVERY id.
